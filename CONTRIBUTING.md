# Contributing

Thanks for your interest in improving Design System MCP Kit.

## Getting started

```bash
git clone https://github.com/ak-shaa/design-system-mcp-kit.git
cd design-system-mcp-kit
npm install
npm run build
npm run typecheck
```

## Making changes

1. Create a branch from `main`.
2. Keep changes focused — one logical change per pull request.
3. Match existing TypeScript style and module layout.
4. Run `npm run build` and `npm run typecheck` before opening a PR.

## Pull requests

- Describe the problem and how your change addresses it.
- Link related issues when applicable.
- Update README or adapter docs if you change public behavior.

## Scope

This project provides a reusable MCP framework and example adapters. Team-specific design system data belongs in consumer repos, not in this kit.
